<h2><a href="https://www.geeksforgeeks.org/problems/assignment-problem3016/1">Job Assignment Problem</a></h2><h3>Difficulty Level : Difficulty: Hard</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">There are <strong>n</strong> persons and <strong>n</strong> jobs that need to be completed, one job per person. Given an n x n cost matrix <strong>mat[][]</strong>, where mat[i][j] represents the time taken by person i to complete job j.</span></p><p><span style="font-size: 18.6667px;">Assign exactly one distinct job to each person such that every person gets exactly one job, and every job is assigned to exactly one person so that the total time taken across all assignments is minimized.</span></p><p><span style="font-size: 18.6667px;">Return this <strong>minimum</strong> total time.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> mat[][] = [[3, 5], [10, 1]]<strong>
Output:</strong> 4<strong>
Explanation: <br></strong>Person 0 takes time 3 for job 0 and 5 for job 1, 
person 1 takes time 10 for job 0 and 1 for job 1.
The optimal assignment is job 0 to person 0 and job 1 to person 1: 3 + 1 = 4.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> mat[][] = [[2, 1, 2], [9, 8, 1], [1, 1, 1]]<strong>
Output:</strong> 3<strong>
Explanation:<span style="font-size: 14pt;"> </span></strong>The optimal assignment is:<br>job 1 to person 0, <br>job 2 to person 1,<br>job 0 to person 2, 
<span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">giving a total cost of 1 + 1 + 1 = 3.</span></span></pre><p><span style="font-size: 14pt;">1 ≤ n ≤ 100<br>1 ≤ mat[i][j] ≤ 10<sup>5</sup></span></p></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Google</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Graph</code>&nbsp;
