Output: </strong>4<strong>
Explanation: </strong>Since k = 1, one wall may be removed. Removing the wall at cell (2, 1) or (1, 2) opens a path connecting the start and destination cells. Following this path reaches the bottom-right corner in 4 steps.<br>    <img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929519/Web/Other/blobid2_1781153650.webp" width="275" height="229"><br></span></pre><pre><span style="font-size: 18px;"><strong>Input: </strong>k = 0, mat = [[0, 1], [1, 0]]<strong>

Explanation: </strong>Since k = 0, no walls can be removed.
