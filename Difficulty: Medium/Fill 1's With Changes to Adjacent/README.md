<h2><a href="https://www.geeksforgeeks.org/problems/fill-array-by-1s0920/1?page=13&category=Arrays%2CStrings%2CJava%2CLinked%20List&company=Amazon%2CMicrosoft%2CGoogle%2CFlipkart&sortBy=submissions">Fill 1's With Changes to Adjacent</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given a binary array <strong>arr[] </strong>consisting of 0s and 1s. In each iteration, all 0s that are adjacent to at least one 1 are converted to 1.</span></p>
<p><span style="font-size: 18.6667px;">Return the <strong>minimum </strong>number of iterations required to make the entire array contain only 1s. If not possible, return <strong>-1</strong>.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong><strong>Input:</strong></strong> arr[] = [1, 0, 1, 0]</span><br><span style="font-size: 14pt;"><strong><strong>Output:</strong></strong> 1</span><br><span style="font-size: 14pt;"><strong><strong>Explanation: </strong></strong>In the first iteration, both 0s have at least one adjacent 1, so they are converted to 1. The array becomes [1, 1, 1, 1]. Hence, only 1 iteration is required.</span></pre>
<pre><span style="font-size: 14pt;"><strong><strong>Input:</strong></strong> arr[] = [0, 0, 1, 0, 0]</span><br><span style="font-size: 14pt;"><strong><strong>Output:</strong></strong> 2</span><br><span style="font-size: 14pt;"><strong><strong>Explanation: </strong></strong></span><span style="font-size: 14pt;">After the first iteration, the 0s adjacent to 1 are converted, and the array becomes [0, 1, 1, 1, 0].</span><br><span style="font-size: 14pt;">After the second iteration, the remaining 0s are converted, and the array becomes [1, 1, 1, 1, 1].</span><br><span style="font-size: 14pt;">Therefore, 2 iterations are required to fill the entire array with 1s</span></pre>
<pre style="font-size: 18.6667px;"><span style="font-size: 14pt;"><strong><strong>Input:</strong></strong> arr[] = [0, 0, 0]</span><br><span style="font-size: 14pt;"><strong><strong>Output:</strong></strong> -1<br><strong>Explanation: </strong>Since the array does not contain any 1<span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">, no 0</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;"> can ever be converted to 1</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;"> in any iteration. Therefore, it is impossible to fill the entire array with 1</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">s, and the answer is </span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">-1</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">.</span></span></pre>
