<h2><a href="https://www.geeksforgeeks.org/problems/number-of-minimum-picks-to-get-k-pairs-of-socks-from-a-drawer--141631/1?page=13&category=Arrays%2CStrings%2CJava%2CLinked%20List&company=Amazon%2CMicrosoft%2CGoogle%2CFlipkart&sortBy=submissions">Minimum Picks for K Sock Pairs</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">A drawer contains socks of <strong>n</strong> different colors, where <strong>count[i]</strong> denotes the number of socks of the <strong>i-th</strong> color. </span><span style="font-size: 18px;">Tony picks socks from the drawer without seeing their colors. </span><span style="font-size: 18px;">Find the minimum number of socks Tony must pick to guarantee at least k matching pairs of socks. </span></p>
<p><span style="font-size: 18px;">If it is impossible to obtain k pairs, return <strong>-1</strong>.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; white-space: normal;">count</span>[] = [3, 4, 5, 3], k = 6</span>
<span style="font-size: 18px;"><strong>Output:</strong> 15</span>
<span style="font-size: 18px;"><strong>Explanation:</strong> The maximum number of pairs that can be formed is 1 + 2 + 2 + 1 = 6. Therefore, all 15 socks must be picked to guarantee 6 pairs.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>count[] = [1, 1, 1], k = 1<br></span><span style="font-size: 18px;"><strong>Output:</strong> -1</span>
<span style="font-size: 18px;"><strong>Explanation: </strong>No pair can be formed because every colour has only one sock. Therefore, obtaining 1 matching pair is impossible.</span></pre>
