<h2><a href="https://www.geeksforgeeks.org/problems/word-boggle4143/1">Word Boggle</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p data-start="361" data-end="504" data-is-last-node="" data-is-only-node=""><span style="font-size: 14pt;">Given a string array <strong>dictionary[]</strong> of size <strong>n</strong> containing distinct words and a character matrix<strong> board[][]</strong> of size <strong>r × c</strong>, find all words from the dictionary that can be formed in the board.</span></p>
<ul>
<li data-start="361" data-end="504"><span style="font-size: 14pt;">A word can be formed by starting from any cell and moving to any of its 8 adjacent cells (horizontally, vertically, or diagonally).</span></li>
<li data-start="361" data-end="504"><span style="font-size: 14pt;"> Each cell can be used at most once while forming a single word.</span></li>
</ul>
<p data-start="361" data-end="504" data-is-last-node="" data-is-only-node=""><span style="font-size: 14pt;">Return all dictionary words that can be formed in the board.</span></p>
<p data-start="361" data-end="504" data-is-last-node="" data-is-only-node=""><span style="font-size: 14pt;"><strong>Note:</strong> The words in the output can be returned in any order.</span></p>

<strong style="font-size: 14pt;">Output: </strong><span style="font-size: 14pt;">["CAT"]
</span><strong style="font-size: 14pt;">Explanation</strong><span style="font-size: 14pt;">: </span><span style="font-size: 18.6667px;">"CAT" can be formed by traversing adjacent cells (8 directions) without reusing any cell.</span><span style="font-size: 14pt;"><br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929908/Web/Other/blobid0_1781869306.png" width="163" height="159"><br></span></span></pre>
